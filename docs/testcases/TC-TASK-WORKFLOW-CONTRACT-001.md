# TC-TASK-WORKFLOW-CONTRACT-001：行為契約桌面驗證

## 方法與證據界線

對照 [行為契約](../task-workflow-contract.md)、[既有內容規則](../task-content-format.md) 與 baseline 做文件桌面推演。下列 `DEMO-WF-*`、來源與結果全部虛構，不建立真實 Task、不呼叫 YouTrack，不代表 plugin、持久化、使用者實測或獨立 reviewer 已通過。

每個變體依給定事實與明確要求推演操作、責任、階段、snapshot、歷史與必要問題。下列紀錄是本次推演的預期輸出，逐項對照後結果為文件一致；外部操作與 human review 另待驗證。所有 snapshot 沿用原有區段，未新增進展欄位。
