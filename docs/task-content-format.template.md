# Task Markdown 模板

依 [內容規則](task-content-format.md) 填寫；[情境示例](task-content-format.examples.md) 可供比對。複製下方整個程式碼區塊，將所有 `<…>` 替換為已知內容或明確語意標記；不要留下占位文字或空白作為答案。名稱依已知目的撰寫，沒有已知目的時先釐清，不補造。

未知填 `待釐清：<缺少或尚未決定的內容>`；確認沒有才填 `無`；不適用填 `不適用：<原因>`。Idea 的方向與下一步可以待釐清；無方向的主要理由可填 `不適用：尚未形成方向`。尚未結案的兩個結案欄位均填 `不適用：尚未結案`。識別尚未取得填 `待釐清：尚未取得識別`，取得後沿用同一識別。

參考條目逐筆填 `位置：<位置>｜用途：<用途>｜存取狀態：<實際狀態及缺少資料>`，沒有參考且已確認才填 `無`；未知能否存取不可寫成已讀。重要變更逐筆填 `<先後序號>｜<變更前> → <變更後>｜理由：<已確認理由或待釐清標記>`，沒有重要變更填 `無`。更新時修正目前 snapshot，並追加重要變更，保留既有順序及理由。

階段依實際情況填 Idea、Draft plan、Implementation plan／實作、PR 或 Close；可跳轉或退回，不要求文件或 Skill。結案類型填完成、取消或停止，記錄結果或原因，下一步可填 `不適用：此 Task 已結案`，未解決事項仍保留。PR 建立或合併不自動結案。

```markdown
# <工作對象>：<目的或期望結果>

- Task 識別：<既有識別或明確語意標記>
- 專案：<已知專案或明確語意標記>
- 標籤：<已知標籤或明確語意標記>

## 目的與背景
- 目的：<已知目的>
- 已知背景：<可得背景或明確語意標記>

## 目前方向
- 方向：<目前方向或明確語意標記>
- 主要理由：<已知理由或明確語意標記>
- 待釐清：<尚未確認事項或明確語意標記>

## 工作狀態
- 階段：<目前階段>
- 下一步：<已知下一步或明確語意標記>
- 阻礙：<已知阻礙或明確語意標記>

## 參考資料
- <參考條目或明確語意標記>

## 重要變更
- <重要變更條目或「無」>

## 結案
- 結案類型：<完成、取消、停止或「不適用：尚未結案」>
- 結果或停止原因：<已知結果、原因或「不適用：尚未結案」>
```
