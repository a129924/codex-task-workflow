# Stable library boundary

This repo imports development tools, not a stable publishing library. Declare
stable-library intent explicitly absent for local work. A README navigation
entry alone does not imply promotion, VERSION changes, release notes or tags.
Post-merge / release actions states no automatic post-merge or release work.

If the request actually requires stable-library promotion, stop for a separately
approved publishing contract. Do not invent timing, registry entries, VERSION
or release phases from the upstream repository. This boundary applies to the
skill, template, examples and checklist equally.
