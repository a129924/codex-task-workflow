# step-creator checklist

- [ ] Explicit path-safe topic and base-plan; unsupported profiles stop.
- [ ] Both shared contracts and exact source plan are readable.
- [ ] All 11 canonical sections; terminal approved, explicit []/none planning
  transitions, exact Implementer next actor and bounded implementation action.
- [ ] All five earlier/rework states BLOCKED before temporary/final writes.
- [ ] Exactly one top-level ordered Implementation Steps; no source repair.
- [ ] One complete selector tuple; primary-worktree=false, no competing tuple.
- [ ] Explicit local-delivery stop and no release; no publication/cleanup shell.
- [ ] Destination absent; no temporary output on blocked preflight.
- [ ] Base frontmatter order: topic, step_profile, source_plan, created.
- [ ] Wire order: Workflow Stages, Actionable Steps/fixed head/context,
  Implementation Steps, Observer fixed tail, Handoff / Gate Notes.
- [ ] Source actor/action and implementation items copied one-to-one verbatim.
- [ ] Only [X]/[ ]; every [X] has exact evidence; [x] pending and warns.
- [ ] Observer only dispatches; concrete verification belongs to role owners.
- [ ] Handoff identifies exact source, shell, selector, evidence and tracker scope.
- [ ] Fully validate then atomic no-overwrite promotion; no partial final file.
- [ ] Only new destination written; Plan Mode drafts conversation only.
- [ ] Return review-ready to independent Reviewer; no self-approval.
